# Fashion Doggie Salon — independent website demo

A temporary English/Spanish design concept by PaceSync Systems for a dog grooming salon in San Antonio. It is not the salon's official website or an authorised booking system.

## Pages
- Home: long, varied introduction, packages, comparison, style finder, Halloween lookbook, gallery, process, reviews, FAQs and contact.
- Grooming: four packages and a readable 14-feature comparison.
- Gallery: category filters, accessible photo dialog and original-post links.
- Our salon: sourced business information and portfolio context.
- Visit: location, contact routes and a WhatsApp enquiry preview.

Every page has an English and Spanish version. Assets and fonts are local; no analytics, backend submissions, credentials or tracking are included. Enquiries open a user-reviewed WhatsApp draft; appointments must be confirmed by the salon.

## Development and hosting
Static HTML, CSS and JavaScript. Serve this directory with any static HTTP server, or GitHub Pages from `main` at the repository root. The repository includes `.nojekyll`; no dependencies or build step are required to host the generated files.

The demo is marked `noindex,nofollow,noarchive`. Per the owner's outreach workflow, unpublish the GitHub Pages deployment after seven days unless Hamza extends it. Retain the repository/source. Do not send outreach without Hamza's review of the exact message.
